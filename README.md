# video-juego-guerreras-k-pop
Las Guerreras K-Pop es un videojuego de acción y combate desarrollado en Python utilizando la biblioteca Pygame. El jugador controla a una de tres guerreras —Zoey, Mira o Rumi—, cada una con habilidades y estilo de combate propios, a través de cinco niveles de dificultad progresiva enfrentando enemigos controlados por inteligencia artificial
